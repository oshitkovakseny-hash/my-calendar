# Тест «Насколько продумана образовательная стратегия вашего ребёнка?»

Лендинг с адаптивным тестом из 7 вопросов для родителей детей 4–18 лет.
Каждый вопрос показывается на отдельном экране (шаге), в конце теста
пользователь указывает почту, и туда отправляется расшифровка результата.

Реализовано на React + Vite, независимо от остального репозитория
(`my-calendar`) — это отдельный проект в подпапке `test-landing/`.

## Как это устроено

- `src/data/questions.js` — все тексты теста: 4 возрастных блока по
  7 вопросов, шкала ответов, общая и тематическая расшифровка (взято из
  приложенного технического задания).
- `src/logic/scoring.js` — подсчёт баллов и логика выбора приоритетных
  рекомендаций (правило приоритета, предупреждение о нагрузке при слабом
  ответе на вопрос 7).
- `src/App.jsx` — весь пользовательский сценарий: стартовый экран → выбор
  возраста → инструкция → 7 вопросов (каждый — отдельный «экран»,
  переключение отражается в адресной строке через `#hash`, поддерживается
  кнопка «Назад» браузера) → форма с почтой → экран результата.
- `src/firebase.js` — сохраняет прохождение в Firestore
  (`quiz_submissions`) и кладёт письмо в коллекцию `mail`.

## Отправка письма с расшифровкой

Проект не содержит собственного email-сервера. Отправка реализована через
официальное расширение Firebase **«Trigger Email from Firestore»**
(`firestore-send-email`): приложение просто добавляет документ в
коллекцию `mail`, а расширение отправляет письмо через настроенный в нём
SMTP.

Чтобы письма реально уходили, один раз настройте это в консоли Firebase
проекта `my-calendar-sync-b88cd` (или своего собственного — тогда
поменяйте конфиг в `src/firebase.js`):

1. Firestore Database → включите базу, если ещё не включена.
2. Extensions → установите **Trigger Email from Firestore**.
3. При установке укажите:
   - SMTP-подключение (например, пароль приложения Gmail, SendGrid,
     Mailgun и т. п.);
   - имя коллекции: `mail` (совпадает с тем, что использует код);
   - отправителя (`From`), который будет виден получателю.
4. Добавьте правила безопасности Firestore, разрешающие публичную запись
   (но не чтение) в `mail` и `quiz_submissions`, например:

   ```
   match /quiz_submissions/{id} {
     allow create: if true;
     allow read, update, delete: if false;
   }
   match /mail/{id} {
     allow create: if true;
     allow read, update, delete: if false;
   }
   ```

Пока расширение не установлено, тест полностью работает и показывает
результат на экране, но письмо в `mail` просто останется не обработанным
документом в базе.

## Разработка

```bash
cd test-landing
npm install
npm run dev
```

## Деплой

Это отдельный проект в монорепозитории. При подключении в Vercel создайте
отдельный Vercel-проект на этот же репозиторий и укажите
**Root Directory: `test-landing`** — тогда `vercel.json` и `vite.config.js`
из этой папки будут использованы автоматически.
